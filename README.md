## 🚀 How to Run Locally

1. Simply double-click `index.html` to open it directly in any modern web browser.
2. Or use a local development server:
   ```bash
   # Using Python
   python -m http.server 3000
   ```
   Open `http://localhost:3000` in your browser.

---

## 🌐 Deployment to GitHub Pages

1. In repository settings on GitHub (`Settings` > `Pages`):
   - Set **Source** to `Deploy from a branch`
   - Set **Branch** to `main` and folder to `/ (root)`
   - Click **Save**
2. The portfolio will be published live at `https://shreya-s-f.github.io/portfolio`!
